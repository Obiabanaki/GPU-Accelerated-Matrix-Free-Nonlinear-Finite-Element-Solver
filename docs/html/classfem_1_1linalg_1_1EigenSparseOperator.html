Detailed Description

Wraps a CPU-resident Eigen sparse matrix.

Used by DirectSolver always, and by ConjugateGradientSolver/GMRESSolver through Phase 2 (CPU-only). Constructed fresh each Newton iteration from GlobalSystem::tangent() — a thin, temporary view, not a long-lived owner. Must not outlive the GlobalSystem it wraps.
