Detailed Description

Orchestrates the Newton-Raphson loop with load stepping.

Composed of (not inherited from) a Mesh, Material, LinearSolver, and BoundaryConditions — every collaborator is touched only through its abstract interface. Grep this class for concrete type names as a design check: there should be none.
