Detailed Description

Abstract interface for a hyperelastic constitutive model.

A Material is a pure function of deformation: it holds material parameters only, no mesh or solver state, so a single instance can be shared safely across every Element that uses it.

Convention (fixed project-wide, see ARCHITECTURE.md):

  • computeStress returns the 2nd Piola-Kirchhoff stress S (reference configuration, symmetric).
  • computeTangent returns the material tangent dS/dE, Voigt-flattened to 6x6 for 3D.
