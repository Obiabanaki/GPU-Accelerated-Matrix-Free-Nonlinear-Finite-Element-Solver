std::unique_ptr< fem::Material > fem::factory::createMaterial ( const std::string &  type,
const std::map< std::string, double > &  params

Constructs a concrete Material from a name and parameter map.

This — together with createLinearSolver below — is meant to be the ONLY place in the codebase (outside each class's own translation unit and tests) permitted to name a concrete class like NeoHookeanMaterial or ConjugateGradientSolver. Grep the rest of the codebase for concrete type names as the project-wide version of the "is the Strategy pattern real" check from ARCHITECTURE.md.

Parameters
typeMaterial name: "neo-hookean" or "mooney-rivlin".
paramsNamed parameter values required by the chosen type (e.g. "mu"/"kappa" for neo-hookean; "c10"/"c01"/"kappa" for mooney-rivlin).
Returns
Newly constructed Material, owned by the caller.
Exceptions
std::invalid_argumentif type is not recognized.
