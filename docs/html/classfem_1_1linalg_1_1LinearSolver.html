Detailed Description

Strategy interface for solving A*du = R, where A is only ever accessed through the abstract LinearOperator interface.

NewtonSolver calls solve(op, R) and never knows or cares whether op wraps a CPU matrix or GPU-resident data, or whether the solve is a dense LU factorization or 500 iterations of preconditioned CG.
