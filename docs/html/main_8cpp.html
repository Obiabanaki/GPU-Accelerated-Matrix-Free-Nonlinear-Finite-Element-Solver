Detailed Description

Composition root for a configured nonlinear FEM simulation.

Reads the JSON input, builds the configured mesh/material/boundary conditions/linear solver, and runs NewtonSolver. The Hex8, material, assembly, Dirichlet, and direct-solver path computes a displacement field; trace-only alternatives such as Tet4 physics and iterative solvers remain incomplete.

Usage: fem_demo <path-to-input.json> e.g.: ./fem_demo examples/example_problem.json
