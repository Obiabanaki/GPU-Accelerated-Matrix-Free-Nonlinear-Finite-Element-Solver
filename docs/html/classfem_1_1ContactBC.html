Detailed Description

Penalty-based contact against a rigid plane.

Step 2.3-stretch: explicitly optional. Adds an asymmetric stiffness/ force contribution when penetration is detected, which is why it's the motivating case for GMRESSolver rather than ConjugateGradientSolver.
