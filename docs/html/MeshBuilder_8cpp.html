Detailed Description

Implementation of buildStructuredCubeMesh.

Node ordering matches Hex8Element.cpp's documented VTK_HEXAHEDRON convention: 0:(-1,-1,-1) 1:(1,-1,-1) 2:(1,1,-1) 3:(-1,1,-1) 4:(-1,-1, 1) 5:(1,-1, 1) 6:(1,1, 1) 7:(-1,1, 1)

For "tet4", each hex cell is split into 6 tetrahedra sharing the main diagonal from local corner 0 to local corner 6 — a standard, widely used hex-to-tet decomposition (see e.g. VTK's own hex->tet conversion).
