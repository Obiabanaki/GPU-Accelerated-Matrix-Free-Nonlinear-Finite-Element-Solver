Detailed Description

Prescribes displacement at specific DOFs via row/column elimination.

Step 1.4. Must be applied with the INCREMENTAL prescribed value at each Newton iteration within a load step, not the total, or load stepping silently applies the full displacement in one shot — see ARCHITECTURE.md.
