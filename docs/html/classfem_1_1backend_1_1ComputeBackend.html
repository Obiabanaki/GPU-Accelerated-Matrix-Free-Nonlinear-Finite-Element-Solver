Detailed Description

Strategy interface isolating where a sparse mat-vec product runs.

ConjugateGradientSolver calls backend.spmv(...) INDIRECTLY, through linalg::BackendOperator — never directly. That's what makes GPU support an additive CudaBackend sibling, not a rewrite of CG. The only class permitted to hold a ComputeBackend& is BackendOperator.
