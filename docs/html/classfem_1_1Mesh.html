Detailed Description

Owns mesh topology (nodes, elements, DOF map) and drives assembly.

Mesh contains no physics: it loops over Elements and delegates all mechanics to them polymorphically. See ARCHITECTURE.md's open question on single-material-per-mesh vs. per-element before relying on the Material parameter below for a multi-material mesh.
