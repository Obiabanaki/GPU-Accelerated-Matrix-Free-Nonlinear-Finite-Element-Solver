Detailed Description

Owns the global tangent stiffness matrix and residual vector for one Newton iteration, plus DOF bookkeeping.

This is the assembly "scratch space" that Mesh::assemble() writes into and BoundaryCondition::apply() modifies in place. Isolating it means the sparse-matrix representation (triplets now, CSR-on-GPU later) can change without touching Element, Material, or BoundaryCondition code.

IMPORTANT: tangent() must not be handed directly to LinearSolver::solve. Wrap it in a linalg::EigenSparseOperator first — see NewtonSolver.cpp.
