Detailed Description

Diagonal (Jacobi) preconditioner: z_i = r_i / A_ii.

Step 2.2. Requires LinearOperator::diagonal() — see the matrix-free tension noted in ARCHITECTURE.md §7 and Preconditioner.hpp.
