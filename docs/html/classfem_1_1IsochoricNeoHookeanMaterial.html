Detailed Description

Isochoric Neo-Hookean law used by the ANSYS UserMat shear benchmark.

The energy is Psi = mu/2 * (J^(-2/3) I1 - 3) + kappa/2 * (J - 1)^2. This is distinct from NeoHookeanMaterial's logarithmic volumetric law.

Compute the material (Lagrangian) tangent modulus C = dS/dE.

Parameters
F3x3 deformation gradient at a Gauss point.
Returns
4th-order tangent, Voigt-flattened as 6x6. Convention: the returned matrix is meant to right-multiply an engineering-strain Voigt vector (shear entries doubled, i.e. [E11,E22,E33,2E12,2E23,2E13]) so that S_voigt = C * E_voigt reproduces S_IJ = C_IJKL*E_KL exactly — see Hex8Element.cpp's file comment, whose B matrix produces exactly that doubled convention for K = B^T*C*B.
