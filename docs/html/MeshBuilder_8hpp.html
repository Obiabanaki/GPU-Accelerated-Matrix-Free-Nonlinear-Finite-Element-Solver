Detailed Description

Generates a structured-grid Mesh from a MeshConfig.

This is real, non-traced code: mesh topology generation (node coordinates, element connectivity) is bookkeeping, not FEM physics, so it's implemented for real even while the rest of the pipeline is in trace mode — this is what lets the input file's mesh options actually produce a different mesh, not just a different log line.
