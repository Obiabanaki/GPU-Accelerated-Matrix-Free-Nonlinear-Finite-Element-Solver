Detailed Description

Strategy interface: approximately solve M*z = r for M ~= A.

setup() is separate from apply() deliberately: A changes every Newton iteration, so the preconditioner must be rebuilt every iteration too — but setup() must be called once per Newton iteration, NOT once per CG iteration. See ARCHITECTURE.md §7 for the diagonal()/matrix-free gap this interface works around.
