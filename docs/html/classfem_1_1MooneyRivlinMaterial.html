Detailed Description

Two-parameter Mooney-Rivlin hyperelastic material.

Step 1.5: second Material subclass, used to demonstrate near- incompressibility handling (selective reduced integration / mixed u-p) and to prove the Material abstraction isn't a single-implementation interface.
