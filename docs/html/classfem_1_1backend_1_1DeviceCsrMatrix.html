Detailed Description

CSR matrix arrays, resident wherever ComputeBackend put them (host memory for CpuBackend, device memory for CudaBackend).

This is the "backend-resident matrix" that BackendOperator wraps. The point of caching it (rather than re-deriving it from Eigen every call) is to avoid re-uploading to the GPU on every CG iteration — see ARCHITECTURE.md's CudaBackend design check.
