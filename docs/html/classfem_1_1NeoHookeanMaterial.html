Detailed Description

Compressible Neo-Hookean hyperelastic material.

Step 0-pre / Phase 0.5: the first, FD-verified Material implementation. Parameterized by shear modulus mu and bulk modulus kappa (or lambda, depending on the compressible formulation chosen — fix and document which one before implementing computeStress).
